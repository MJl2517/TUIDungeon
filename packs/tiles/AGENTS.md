# Работа с очередью тайлов

Когда пользователь просит обновить/добавить тайлы из просмотрщика:

1. Прочитай только `tools/tileset-viewer/tile-requests.md` от корня проекта.
   Это очередь незавершённых заданий. Если очередь пуста, сообщи об этом.
   Не перечитывай архивные промпты из `tasks.json`, старых отчётов или резервных
   копий, если пользователь явно не просит доработать выполненную партию.
2. Реализуй выбранные задания в `packs/tiles`, используя существующие механики.
   При необходимости читай определения и код, относящиеся к текущему заданию.
3. Проверь результат. Заверши только реализованные и проверенные задания
   командой `./tileset-viewer.sh --complete ID@ВЕРСИЯ --note "Результат и проверки"`.
   Точные ID и версии скопируй из рабочего MD. На Windows используй
   `.\tileset-viewer.bat`. Несколько токенов можно передать одной командой.
   Галочки атласа определяются автоматически по назначениям символов в `packs/tiles`.
   После изменения назначений обнови снимок командой `./tileset-viewer.sh --sync-progress`
   (Windows: `.\tileset-viewer.bat --sync-progress`) и включи `progress.json` в коммит.
   Команда `--complete` также обновляет снимок. Не исправляй галочки вручную:
   отдельный импорт рисунка в `symbols` ещё не считается реализованным тайлом.
4. Не помечай всю очередь выполненной автоматически и не выводи статус задания
   из зелёных галочек `progress.json`: они отмечают картинки, а не выполнение
   полного промпта. При прерывании оставь незавершённые задания в очереди.

Статусы и архив сохраняются в `tasks.json`; рабочий MD пересобирается командой.
Если команда сообщает об изменённой формулировке, перечитай актуальную очередь
и проверь изменения перед завершением. Не исправляй статусы вручную ради обхода
проверки версии. Исходный выполненный запрос сохраняется; доработка — новый ID.
