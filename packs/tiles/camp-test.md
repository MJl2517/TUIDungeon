# Лагерь, свет, останки и паутина

В студии откройте **`tiles:camp_lab`**. Для проверки сбора, воды и света подойдёт
`dev:empty_tester`, для рецептов — `dev:roadmap_tester`. Принадлежности лежат
в шкафу у старта. Запуск напрямую:

```text
run.bat --test-map tiles:camp_lab --test-class dev:empty_tester --seed 42
```

На Linux используйте `./run.sh` с теми же аргументами.

| Ячейки | Объекты и проверка |
|---|---|
| 692 | `tiles:cooking_pot`: нагреваемый сосуд на 3 порции. Наберите воду, перелейте или опустошите; вес зависит от содержимого. Есть рецепт ковки котелка. |
| 505 | `tiles:campfire`: добавьте древесину, зажгите факелом. Горит час на единицу древесины; даёт свет и тепло для крафта. |
| 506 | `tiles:magic_fire`: безопасный постоянный свет. Проходим, не обжигает, не поджигает и не заменяет источник тепла. В палитре есть пять цветовых вариантов; цвет можно менять у экземпляра. |
| 646–647, 736–737 | Четыре отдельных объекта останков с контейнерами. По уточнению пользователя 646–647 также являются останками, а не опорами. Добыча задаётся в содержимом экземпляра; на полигоне есть пробная добыча. |
| 739 | `tiles:candle_fixture` и `tiles:candle`: свечу можно снять, взять в руку и зажечь. Остаток топлива сохраняется. |
| 740 | `tiles:torch_stand`: снимите обычный факел и установите обратно в пустую стойку. Топливо сохраняется. |
| 741 | `tiles:candelabra`: заменяемая свеча; сам подсвечник переносится как мебель. При упаковке пламя гаснет, топливо сохраняется. |
| 688–689 | `tiles:gravestone`, `tiles:grave_slab`: надгробие и плоская проходимая плита. Отдельные объекты поверх пола. |
| 698 | `tiles:thread` (белые нити), `tiles:gold_thread` (золотая нить), `tiles:leather_strip` (коричневые полоски кожи). Стакуются. Рецепты ведут к верёвке, магическому фокусу и бурдюку. |
| 691 | `tiles:well`: неисчерпаемый источник чистой воды. Тип воды и конечный запас при необходимости задаются у экземпляра. |
| 690 | `tiles:hatch_transition`: переход при входе на клетку. Назначение выбирается при размещении. На полигоне ведёт в `tiles:camp_annex`, там есть люк обратно. |
| 603 | `tiles:web_hanging`: сбор за 1 ход даёт паутинное волокно. Возвращается через 10 игровых дней (14 400 минут) после сбора. |
| 738 | `tiles:web_dense`: закрывает движение, обзор и свет. Рубящее оружие должно быть в руках; расчистка — 3 хода, с паузой и сохранением. Можно сжечь. |

Десятидневное восстановление, три хода расчистки и требование рубящего оружия
заданы запросом. Прочность паутины (5/10), количество волокна (1/2), вес
канделябра (2 кг) и стоимость новых рецептов — стартовый баланс.
Канделябр использует существующую механику одного сменного источника света.

В `tiles:camp_annex` полная тьма вне радиуса магического огня: удобно проверять
освещение отдельно от яркого основного зала. Удаление объектов, оставшийся пол,
содержимое сосудов, топливо, добыча и восстановление хранятся в сохранении.

Проверки: `python -m unittest tests.test_tiles_camp -q`.
