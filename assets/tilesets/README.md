# Оформление карты

Оконная игра: **Настройки → 3: Текст / 4: Символы**. Из игры — **Esc → 5**.
Выбор сохраняется в `saves/appearance.json`; прежний `kenney_1bit` совместим
с режимом «Символы». Терминал использует текстовые знаки библиотеки.

Источник графики — документы `packs/*/symbols/*.json`, а не отдельная таблица
назначений. Маски 16×16, цвет и фон определяются игровым объектом. Карта:
квадратные клетки 32×32 по умолчанию, масштаб 16–96, шаг 16, без сглаживания.

В библиотеку импортирован весь Kenney **1-Bit Pack 1.2**, 49×22 клетки.
Оригинал: `../1 bit/Tilesheet/monochrome-transparent_packed.png`.
Лицензия **CC0**, текст: `../1 bit/License.txt`.
Источник: https://kenney.nl/assets/1-bit-pack.
В каждом импортированном документе сохранены координаты и происхождение.
Неразобранные рисунки требуют согласования перед назначением.

`kenney_1bit.json` оставлен как исторический материал; загрузчики не используют
его как источник действующих назначений. Неверные старые назначения исправлены
в ходе [ревизии](../../docs/symbol-audit/README.md).
