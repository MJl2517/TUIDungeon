# Оформление карты

В оконной игре: **Настройки → 3: Текст / 4: Kenney 1-Bit**.
Из игры настройки доступны через **Esc → 5**. Переключение применяется сразу,
не расходует ход и сохраняется в `saves/appearance.json`. По умолчанию используется
текст. Терминальный режим всегда остаётся текстовым.

Первый набор использует `../1 bit/Tilesheet/monochrome-transparent_packed.png`
из Kenney **1-Bit Pack 1.2**, 49×22 клетки по 16×16 пикселей.
Лицензия CC0 и оригинальные материалы находятся в `../1 bit/License.txt`.
Источник: https://kenney.nl/assets/1-bit-pack.

`kenney_1bit.json` задаёт координаты рисунков `[столбец, строка]` от нуля.
`content` связывает элементы базового пакета с рисунками; `glyphs` задаёт
общие символы для старых карт. `special` содержит героя и состояния дверей.
Рисунки привязаны к элементам контента, а не к цвету или символу: кровать и дверь
с одинаковой буквой не путаются, полутьма сохраняет нужное изображение.
Неописанный контент остаётся текстовым. Карты и сохранения не переписываются.

Графика загружается один раз при первом выборе. Рисунки сохраняют игровую палитру,
затемнение и видимость; курсор осмотра остаётся `X`. Для карты используется
отдельный квадратный атлас, для меню — прежний шрифт с кириллицей.
PNG и JSON включены в проект; установки системных шрифтов и новых зависимостей
не требуется. При отсутствии набора игра возвращается к текстовому оформлению.
