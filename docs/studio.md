# Разработка контента в Studio

## От рисунка к подземелью

1. Запустите `./run.sh --studio`. В «Графике» создайте документ и задайте ID.
   Нарисуйте слой. `Shift + клик` по цветовой палитре выбирает фон; обычный
   клик — цвет символа. Прозрачный фон сохраняет фон нижнего слоя, а ластик
   делает всю клетку прозрачной. Слои рисуются в порядке списка, от первого к последнему.
2. Сохраните арт. Его можно выбрать в форме монстра, предмета или другого
   визуального объекта. Поле «Символ на карте» независимо от большого рисунка:
   монстр занимает одну игровую клетку.
3. В «Монстрах» создайте шаблон, заполните HP, КД, скорость, инициативу,
   характеристики, обычные и особые действия. Обычные действия ссылаются на
   библиотеку; особое действие находится прямо в шаблоне. Для `attack` задайте
   кубики урона и характеристику, для `special` — последствия. Сохраните и
   выполните действие в песочнице с выбранным seed.
4. В «Подземельях» создайте документ. Размещайте тайлы кистью/областью/заливкой,
   либо добавьте готовый арт в слое «Рисунки». Опция «Начальные маски тайла»
   копирует его свойства только в момент размещения. После этого маски независимы.
5. Переключите слой на «Проходимость» или «Преграды обзору», задайте значение
   флажком и рисуйте поверх графики. Цветные оверлеи можно скрыть. Ластик меняет
   значение маски на противоположное выбранному. Рисование арта маски не меняет.
6. Добавьте ловушку и точку интереса из библиотеки. Точка интереса ссылается
   на испытание с текстом, вариантами, проверками, требованиями и последствиями.
   «Старт героя» задаёт стартовую клетку; «Переходы» выбирают целевую карту.
7. Инструмент «Выбрать» выделяет область и объект под курсором; в инспекторе
   можно выбрать один из нескольких объектов клетки. «Перенести» переносит
   выбранный объект или выделенную область, «Копировать область»/«Вставить»
   копирует графику, маски и размещения с новыми ID.
8. Сохраните карту и нажмите «Тестировать карту». Изменения черновика нужно
   сохранить перед тестом. WASD или кнопки двигают героя. В правой панели видны
   доступные взаимодействия, броски и ресурсы. Перезапуск создаёт чистые экземпляры.
   В TUI карта запускается через `./run.sh --map pack:map_id`.

Скрытость ловушки влияет на отрисовку игры: редактор показывает её для автора,
игра раскрывает после срабатывания. Монстры блокируют проход, но пока не
двигаются и не начинают бой. Размещённые предметы показываются на карте;
подбор и использование из TUI пока не добавлены. Обзорная маска хранится для
будущего FOV и сейчас не скрывает клетки.

## Пакеты и внешние правки

«+ Пакет контента» создаёт манифест и папки категорий. Выберите зависимости
перед использованием чужих шаблонов. Пакет зависит только от существующих
пакетов; циклы запрещены. Библиотека обновляется каждые пять секунд.

Сохранение использует версию содержимого файла и атомарный `os.replace`.
Если файл поменял агент или внешний редактор, студия оставляет черновик и
предлагает перечитать. Удаление блокируется, пока на объект есть ссылки.
Документы проверяются при загрузке и до записи. Предупреждение о недостижимом
участке не мешает сохранению: изолированная комната может быть намеренной.

Студия не переименовывает существующие ID: дублируйте документ и измените ID
при создании. Изменения Python-кода требуют перезапуска сервера; JSON-правки
обнаруживаются автоматически.

## Добавление зарегистрированного эффекта

Сначала используйте существующие эффекты в обычном `special`-действии,
заклинании, предмете, испытании или ловушке. Для новой механики создайте
`tuidungeon/domain/plugins/heal_percent.py`:

```python
from pydantic import Field
from ..mechanics import Parameters, mechanics
from ..effects import EffectOutcome

class HealPercent(Parameters):
    percent: int = Field(ge=1, le=100, description="Процент максимальных HP")

def apply(params: HealPercent, target, dice):
    amount = target.heal(max(1, target.max_hp * params.percent // 100))
    return EffectOutcome("heal_percent", amount=amount)

mechanics.register(
    "heal_percent", HealPercent, apply,
    name="Лечение в процентах",
    description="Восстанавливает часть максимальных HP выбранной цели.",
)
```

В `tuidungeon/domain/plugins/__init__.py` добавьте:

```python
from . import heal_percent
```

После перезапуска студии новый пункт появится в формах эффектов. Его параметры
строятся из `HealPercent.model_json_schema()` и проверяются той же моделью до
сохранения и при выполнении обработчика. JSON:

```json
{"kind": "heal_percent", "params": {"percent": 25}}
```

Обработчик изменяет переданный экземпляр и возвращает фактический результат.
Он не загружает файлы и не создаёт собственный генератор случайности: используйте
переданный `dice`, чтобы сохранить воспроизводимость. Проверяйте параметры
в модели, не выполняйте частичные изменения перед проверкой допустимости.
Пассивная КД использует специальные свойства снаряжения; новые эффекты работают
в активных последствиях. Стратегии `CharacterAction` и абстрактный `Challenge`
остаются точками расширения самого игрового кода.

## Инструменты разработчика

- `npm run dev --prefix studio`: Vite на localhost с прокси к API :8765.
- `npm run format --prefix studio`: форматирование TypeScript/React исходников.
- `.venv/bin/ruff format tuidungeon`: форматирование Python.
- `npm run build --prefix studio`: типизация и автономная production-сборка.
- `npm test --prefix studio`: история документов, инструменты рисования,
  изменение размеров и композиция.
- `.venv/bin/python -m tuidungeon.content.export_schemas /tmp/dungeon-schemas`:
  выгрузка схем для внешних редакторов/агентов.
- `/api/schemas`: схемы всех категорий, шаблоны создания и метаданные механик.
- `/api/library`: пакеты, категории, версии и краткие карточки документов.
- `scripts/check_studio_browser.py`: проверка пользовательского сценария в
  реальном браузере на временной копии контента.

Клеточная графика ограничена 256×256 для предсказуемого редактирования.
PNG/растры не являются исходником: редактируемый формат — JSON с символами.
Валидация ширины использует `wcwidth`; в браузере применяется моноширинный
системный шрифт. Терминалы с неоднозначной шириной Unicode могут отличаться:
проверяйте выбранные символы в целевом терминале.
