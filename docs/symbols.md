# Единая библиотека символов

Откройте `./studio.sh` (Windows: `.\studio.bat`) → **Графика → Символы**.
В формах документов назначайте изображения объектам, поверхностям,
вариантам и состояниям дверей. Игровые механики остаются в этих определениях;
символ задаёт только рисунок и текстовый знак.

Для зеркального варианта не копируйте запись библиотеки: у внешнего вида
объекта/тайла есть `mirror_x`, у клетки арта — такое же свойство. Маска символа
не меняется; отражение применяется при отображении. В редакторе карты Shift
отражает кисть и её полупрозрачный предпросмотр. [Управление и формат карты](tiles.md#отражение-и-силуэт-кисти).

## Размер и формат

Исходник — **16×16**, бинарная маска: `1` рисует цветом объекта, `0` прозрачна.
Фон также задаётся объектом. Карта по умолчанию показывает квадратные клетки
**32×32**, увеличение без сглаживания: 16–96 с шагом 16.
Текст интерфейса и размеры многоклеточных символьных артов сохраняются.

Документ лежит в `packs/<pack>/symbols/<id>.json`:

```json
{
  "schema_version": 1,
  "id": "my_lamp",
  "name": "Настольная лампа",
  "group": "Освещение",
  "tags": ["лампа", "свет"],
  "glyph": "!",
  "pixels": ["0000000000000000", "0000001111000000", "0000011111100000", "0000111111110000", "0001111111111000", "0000000110000000", "0000000110000000", "0000000110000000", "0000000110000000", "0000000110000000", "0000000110000000", "0000000110000000", "0000001111000000", "0000011111100000", "0000000000000000", "0000000000000000"],
  "source": {"name": "Авторский рисунок", "license": "Укажите условия использования"}
}
```

Маска строго 16 строк по 16 знаков `0`/`1`. `glyph` — один печатный знак шириной
в одну колонку; широкие и составные знаки отклоняются. Ссылка из объекта —
`"symbol": "my_pack:my_lamp"`. Для другого пакета нужна зависимость в манифесте.
Цвета `foreground`/`background` хранятся отдельно.

## Рисование

Создайте символ через библиотеку или окно выбора в форме объекта. Укажите
название, категорию и текстовый знак. ID после сохранения фиксируется.
Любой структурно корректный символ доступен для назначения сразу. Старое поле
`reviewed` читается для совместимости и не влияет на назначение или готовность.

На холсте доступны кисть **B**, ластик **E**, заливка **F**, линия **L**,
прямоугольник **R**, выделение **S**, перенос **V**. После выделения:
**Ctrl+C**, **Ctrl+V**, затем щелчок по месту вставки. Есть отражения, поворот,
**Ctrl+Z / Ctrl+Shift+Z**, сетка, масштаб и предпросмотр на разных фонах.
Клавиши инструментов работают, когда холст в фокусе.

PNG экспортируется в исходном размере с прозрачностью. Импорт принимает PNG
16×16 или лист размером, кратным 16, до 1024×1024; изображения не растягиваются.
Выберите маску по прозрачности или яркости и порог, проверьте выбранные клетки,
подтвердите преобразование. Одну клетку можно загрузить в текущий рисунок,
несколько — создать как отдельные неразобранные записи выбранного пакета.
Укажите источник и лицензию импортированной графики в сведениях об источнике.

## Назначение

Щёлкните изображение в форме, варианте внешности, инспекторе экземпляра карты
или символьной мастерской. Поиск библиотеки учитывает имя, ID, теги и знак;
доступны фильтры пакета и категории. Изменение общей записи обновляет
всех пользователей. **Дублировать и назначить** создаёт независимый вариант.
Сведения об использовании доступны у открытого документа; используемый символ
удалить нельзя.

Для деревянной, стальной и адамантиевой двери доступны закрытое, запертое
и открытое состояния; для прутьев ещё погнутое; для каменной плиты — закрытое.
Новые шаблоны предметов для этих состояний не нужны.

Многоклеточные арты сохраняют слои, цвета и прозрачность. Кисть выбирается из
той же библиотеки. Обычный текст и TXT разрешают знаки через библиотеку и при
необходимости создают записи из встроенного шрифта в выбранном пакете.

## Игра и совместимость

В настройках оконной игры выберите **Текст** или **Символы**. Выбор сохраняется
в `saves/appearance.json`; старое значение `kenney_1bit` читается как «Символы».
Терминальный режим выводит `glyph` записи. Освещение, скрытность, курсоры,
цвета и мигание горящих дверей применяются поверх графики.

Python и студия разрешают одну и ту же ссылку. Оконная игра собирает атлас один
раз при включении режима; студия сохраняет растровые предпросмотры до изменения
версии документа. Старые карты, сохранения, `glyph`/`char` читаются без обязательной
миграции. Неизвестный старый знак имеет текстовый резервный вид; загрузчик
сообщает о визуальных определениях без назначения. Свободный ввод картинки
в формах заменён выбором символа; JSON совместимости остаётся читаемым.

## Перенос и миграция

Копируйте целиком папку своего пакета вместе с `symbols/`, `manifest.json`
и всеми пакетами-зависимостями. Маска находится внутри JSON: отдельный атлас
на другом компьютере не нужен. Не копируйте `.venv` и `node_modules` между ОС.

Проверка и повторная миграция поставляемых пакетов:

```bash
./run.sh --validate-content
PYTHONPATH=. .venv/bin/python scripts/migrate_symbols.py          # Только проверка
PYTHONPATH=. .venv/bin/python scripts/migrate_symbols.py --apply  # С резервной копией
```

До изменения файлов создаётся `backups/symbols_<дата>/`. Миграция проверяет,
что механические данные, координаты и маски неизменны; повторный запуск безопасен.
Сводка: [ревизия графики](symbol-audit/README.md), машинный список назначений —
`symbol-audit/inventory.json`. Старый `assets/tilesets/kenney_1bit.json` сохранён
для истории и больше не управляет отображением.

Ориентация — свойства внешнего вида, а не отдельные копии символов:
`rotation` принимает 0, 90, 180 или 270 градусов по часовой стрелке,
`mirror_x` отражает результат поворота по горизонтали экрана. У объектов
они задаются в шаблоне или `overrides` размещения; поверхности используют
сетки `tile_rotations` и `tile_mirrors` относительно шаблона. Старые карты
получают нулевые углы автоматически. Студия и оконная игра одинаково
преобразуют пиксели; текстовый режим сохраняет исходный знак.
