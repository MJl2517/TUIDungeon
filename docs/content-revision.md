# Ревизия контента и единый источник данных

Ревизия от 9 октября 2026 года убрала 173 дублирующих документа из рабочего
каталога: 156 тайлов-копий механических объектов и 17 повторных определений.
Ещё 72 определения перенесены из `tiles/` в `objects/`.

| --- | ---: | ---: |
| Поверхности `tiles` | 434 | 206 |
| Окружение `objects` | 0 | 72 |
| Снаряжение `equipment` | 74 | 60 |
| Точки интереса `points_of_interest` | 72 | 70 |
| Ловушки `traps` | 36 | 35 |

## Где создавать новый объект

- `tiles/`: пол, стены, вода, природный рельеф. Тайл задаёт рисунок и начальные маски.
- `objects/`: мебель, двери, стационарный свет, рисунки переходов и механизмы.
- `equipment/`: всё, что подбирают в инвентарь. Символ, цвета, вес и механика находятся здесь же.
- `traps/`: опасные клетки, включая огонь и кислоту; рисунок и проверка входят в шаблон.
- `points_of_interest/`: контейнеры, алтари, надписи и другие текстовые взаимодействия.

Не создавайте дополнительный тайл для предмета, ловушки или сундука. Выберите его
собственный раздел в палитре карты. Размещение хранит `ref`, координаты и локальные
`overrides`. Двери используют специальный слой `doors`, но ссылаются на `objects/`.
Файл определения существует в одном месте; сессия хранит своё изменяемое состояние.

Объекты находятся поверх поверхности. Забранный меч исчезает, оставляя пол.
Мебель добавляет свои ограничения движения и обзора; маски поверхности остаются
отдельными. В инспекторе экземпляра можно изменить `walkable` и `blocks_sight`.
Чтобы разрешить проход через стол, задайте столу `walkable: true`; красный оверлей
показывает итоговую геометрию, включая объекты и двери.

`map_light` у ловушек и точек интереса задаёт стационарное освещение; окружение
использует `brush.light`. Явный источник из слоя `lights` на той же клетке имеет
приоритет. Переносное освещение предметов по-прежнему задаётся полем `light` и
расходует топливо по игровым правилам.

## Что объединено

Кинжал, меч и посох из окружения объединены с основными предметами. Разные рисунки
щита принадлежат одному щиту. Еда, пища и рацион используют дорожный паёк;
лечебные зелья — основной шаблон зелья. Объединены повторные ключ, запертый сундук,
золото и шипы. Масло остаётся единым предметом для фонаря и броска.

Внешние варианты хранятся в `variants`: название варианта, символ, передний цвет
и фон. Выберите объект инструментом **V**, затем «Вариант внешнего вида».
Выбор записывает только визуальные поля в `overrides`, не копирует механику.
Механические отличия старых размещений сохранены локально: старый декоративный
меч с уроном `1d6` не превращается молча в новый меч с `1d8`.

Одинаковые имена разных назначений уточнены: напольная плита и каменная дверь,
ступени рельефа и переходы, стационарный факел и переносной факел. Различающиеся
материалы, формы мебели, оружие и значимые варианты окружения сохранены.

## Совместимость и проверка

Игра, студия и `default_catalog()` используют `packs/`. Каталог
`tuidungeon/content/data/` — архив прежнего формата для явного `--content-dir`,
импорта и тестов совместимости; обычная игра его не загружает.
`content/compatibility.json` хранит правила переноса удалённых ссылок и старые
шаблоны для восстановления сохранений. Эти записи не входят в библиотеку,
палитру, снимки игровых определений или отдельные игровые сущности.

Старые базовые ссылки преобразуются при загрузке карты и сохранения. Повторная
миграция ничего не меняет. Скрипты импорта не возвращают удалённые копии в base.
Рабочие карты перенесены с сохранением координат, ID размещений и локальных
настроек; авторские полигоны не пересоздавались генератором.

```bash
python -m scripts.audit_content           # Проверка каталога без записи
python -m scripts.audit_content --json
python -m scripts.migrate_content         # Какие карты требуют записи нового формата
python -m scripts.migrate_content --write # Проверка, резервная копия, атомарная запись
```

Для другого каталога добавьте `--packs-dir путь/к/packs`.
Перед миграцией сохраняются исходные файлы. Основная копия этой ревизии:
`backups/content-revision-20261009-115740/`; копия уточнений названий и вариантов:
`backups/content-names-20261009-135234-694358/`.

Аудит проверяет все установленные пакеты и сигнализирует о повторном появлении
тайлов-копий и удалённых определений. Отдельно перечисляет незавершённый контент:
у десяти артефактов пока не заданы особые свойства. Они доступны для переноса и
осмотра; новые магические эффекты в рамках ревизии не придуманы.

## Поиск и обновление студии

При непустом поисковом запросе библиотека ищет по всем категориям и пакетам.
Палитра карты ищет все размещаемые поверхности, объекты, предметы, ловушки,
взаимодействия, существ и рисунки. Выбор результата автоматически переключает
нужный слой. Фильтры временно не ограничивают поиск; после очистки строки работают
обычные фильтры. Поиск учитывает имя, ID, описание, теги, группу и поля загруженного
шаблона, включая варианты внешнего вида.

Проверка внешних изменений выполняется в фоне. Неизменившийся каталог не вызывает
повторную загрузку ресурсов; фоновое обновление не закрывает редактор и не сбрасывает
его состояние. Холст меняет свой размер только при изменении размера или масштаба,
а отрисовка завершается до показа кадра браузером.
