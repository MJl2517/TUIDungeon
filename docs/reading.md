# Записки и журнал

В студии выберите категорию **Взаимодействия**, группу **Записки**.
Готовые шаблоны: каменная табличка, чужой дневник, листы с записями,
доска с заданиями. Разместите выбранный шаблон на карте.

В форме шаблона включите **Текст для чтения** и задайте заголовок и страницы.
Каждая страница — многострочный текст. Чтобы менять только один экземпляр,
выберите **Выделение (V)** → объект → **Клетка** → **Свойства экземпляра**
и переопределите `reading`. Название объекта и заголовок текста независимы.
Текст можно добавить и к существующей точке с испытанием или контейнером.

Пример поля в документе `points_of_interest` или в `overrides` размещения:

```json
{
  "reading": {
    "title": "Записки караванщика",
    "pages": [
      "Первый день.\n\nМы добрались до переправы.",
      "Второй день. Дорога ушла под воду."
    ]
  }
}
```

Подойдите к видимому объекту и нажмите **Enter**, затем выберите **Прочесть**.
Заголовок окна берётся из заголовка текста; **←/→** листают страницы,
**Esc** возвращает к действиям. Длинные страницы автоматически делятся
по высоте игрового окна, абзацы сохраняются. Чтение не расходует ход и время.

**J** открывает журнал: Квесты, Записи, Рецепты, Бестиарий, Личный дневник.
В **Записях** находятся прочитанные тексты: «название — название локации».
**↑/↓**, **Enter** выбирают запись, **PgUp/PgDn** переключают страницы списка.
**Esc** возвращает в список, меню журнала и игру; **J** закрывает меню журнала.
Остальные четыре раздела пока пусты. Доска с заданиями содержит текст объявлений;
автоматическое принятие и отслеживание квестов пока не реализовано.
Журнал событий по-прежнему открывается на **L**.

Запись появляется при первом чтении. Сохранение хранит копию текста и локацию;
повторное чтение того же объекта не создаёт дубликат. Объекты на разных картах
или с разными ID сохраняются отдельно, даже если названия совпадают.
Новая игра начинает пустой журнал, старые сохранения без записей совместимы.

Проверочная карта с четырьмя объектами:

```sh
./run.sh --test-map dev:reading_room
```

Windows: `run.bat --test-map dev:reading_room`.
