# Материалы и горючесть

Общие теги для предметов, поверхностей, объектов, ловушек и точек взаимодействия:

| Тег | Значение |
| --- | --- |
| `flammable` | Горючий: материал может пострадать от огня |
| `wooden` | Деревянный или содержит существенные деревянные части |
| `поджог` | Инструмент для поджигания: кремень и кресало, факел |

Это независимые свойства. Масло, бумага, ткань и кожа горючи, но не деревянные.
Деревянную рукоять кирки, топора, копья и молота учитываем как часть предмета.
Металлическая головка инструмента сохраняет свои остальные свойства.
Тег горючести задаёт свойство цели; темп горения, урон и разрушение задаёт
механика объекта. Он не даёт предмету действие «Поджечь» — для него нужен
тег инструмента `поджог`.

В базовом каталоге размечены:

- Вся мебель; лежанка — ткань, остальные текущие виды — с деревянными частями.
- Деревянные двери, ограды, настилы, подпорки, балки, деревья.
- Бочки, сундуки, ящики; тканевые мешки получают только `flammable`.
- Луки, древки и рукояти подходящего оружия, стрелы, болты, щиты и факелы.
- Книги, свитки, карты, записки, пергамент, перо, верёвки, одежда и кожа.
- Масло, свечи, еда, растительность, грибы, паутина и органический мусор.

Камень, металл, стекло и керамика, вода, кислота, кости и неопределённые
магические артефакты не получают этих тегов без основания в описании.
Для текущей лёгкой брони принят горючий кожаный / тканевый материал.

В студии у поля «Теги» есть флажки **Горючий** и **Деревянный**.
Поиск по русским названиям и исходным идентификаторам работает в библиотеке
и игровом инвентаре. Осмотр предмета / клетки показывает эти свойства.
Локальные настройки экземпляров могут переопределять список тегов.

Материал хранится в собственном шаблоне предмета или объекта. Дополнительный
тайл-копия для него не нужен. Поверхности имеют свои теги; настройки экземпляра
могут переопределить материал независимо от общего шаблона.
Структура и совместимость прежних ссылок: [ревизия контента](content-revision.md).

Тип урона и поджог разделены: обычный огненный урон не включает горение двери.
Для воспламенения требуется явное действие/свойство источника; масло сохраняет
собственную реакцию на огонь. Расчёт защиты и взаимодействия материалов:
[система урона](damage.md).

Разметка базового каталога воспроизводима:

```bash
python -m scripts.tag_materials          # показать количество изменений
python -m scripts.tag_materials --write  # проверить и добавить недостающие теги
```

Используйте Python из окружения проекта. Скрипт обрабатывает `packs/base/`
и старый каталог `tuidungeon/content/data/`, сохраняет остальные поля и теги,
не изменяет пользовательские пакеты. Повторный запуск ничего не добавляет.
Правила импорта: `tuidungeon/content/materials.py`.

Расширенный словарь материалов, источников воздействий, возможностей и состояний: [игровые теги](gameplay-tags.md). Старые `wooden` и `flammable` сохранены без переименования.
