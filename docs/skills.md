# Навыки, мастерство и инструменты

Навыки используют основу D&D 2024 (SRD 5.2.1). Владения инструментами — отдельная система по правилам проекта.

## Проверки

Проверка навыка: `d20 + модификатор характеристики + БМ` при владении. Без владения добавляется только характеристика. Экспертиза заменяет БМ на `2 × БМ`; повторные источники не складываются. Характеристика может явно переопределяться испытанием. Натуральные 1 и 20 сами по себе не определяют исход проверки.

| Уровень | Бонус мастерства |
| --- | --- |
| 1–4 | +2 |
| 5–8 | +3 |
| 9–12 | +4 |
| 13–16 | +5 |
| 17–20 | +6 |

Пассивное значение: `10 + итоговый бонус навыка`. Преимущество добавляет 5, помеха вычитает 5; вместе они отменяются. Обычные активные проверки с преимуществом/помехой используют два d20.

| Характеристика | Навыки |
| --- | --- |
| Сила | Атлетика |
| Ловкость | Акробатика, Ловкость рук, Скрытность |
| Интеллект | Магия, История, Расследование, Природа, Религия |
| Мудрость | Уход за животными, Проницательность, Медицина, Внимательность, Выживание |
| Харизма | Обман, Запугивание, Выступление, Убеждение |

## Получение и сохранение

Воин выбирает 2 навыка из списка класса, плут — 4, волшебник — 2. Предыстория выдаёт два указанных в ней навыка. Плут выбирает экспертизу двух освоенных навыков. При создании: цифры 1–6 отмечают варианты, 8/9 листают страницы, 7 подтверждает полный выбор. Лист персонажа показывает все 18 навыков и итоговые бонусы; PgUp/PgDn листают его.

Расовые навыки можно задать полем `races.skills`; текущие расы их не выдают. Дубликат между фиксированными расовыми и фоновыми владениями заменяется отдельным выбором неизвестного навыка. Выбор класса исключает уже освоенные навыки. Старые сохранения без новых полей получают детерминированные начальные владения из класса и предыстории; новые сохраняют точный выбор.

Запуск теста карты напрямую пропускает создание и выбирает первые допустимые навыки. Пустой испытатель не получает навыки класса или инструменты автоматически.

## Инструменты

Наличие инструмента, владение им и экспертиза — разные состояния. Инструмент не требует владения каким-либо навыком. Его проверка: `d20 + модификатор указанной характеристики + БМ`, с отдельной экспертизой инструмента — `+ 2 × БМ`. Без владения остаётся только характеристика. Навыки и их экспертиза не меняют эту проверку и не дают ей автоматического преимущества.

Экспертиза инструмента хранится отдельно и не расходует места выбора навыков или их экспертизы. Она может выдаваться классом/предысторией; эти источники также выдают соответствующее владение. Лист персонажа перечисляет инструменты отдельно. Все владения и экспертизы сохраняются в игре.

Обычный крафт выполняется без броска: рецепт проверяет наличие инструментов и явно требуемые владения. Броски используются только там, где автор задал испытание или рискованную работу.

## Поля студии и контента

| Поле | Назначение |
| --- | --- |
| `classes.skill_choices` | Допустимые навыки класса, стабильные английские ID |
| `classes.skills_known` | Число выбранных навыков |
| `classes.expertise_count` | Число выбранных экспертиз навыков при создании |
| `backgrounds.skills`, `races.skills` | Фиксированные владения навыками |
| `classes/backgrounds.tool_proficiencies` | Независимые владения инструментами, например `lockpicks` |
| `classes/backgrounds.tool_expertise` | Независимая экспертиза инструментов |
| `challenges.choices[].ability` | Характеристика проверки |
| `challenges.choices[].skill` | Навык проверки, например `athletics` |
| `challenges.choices[].tool` | Инструмент проверки; при указании навык не участвует |
| `recipes.check.skill` | Навык явно рискованного рецепта; требуемое владение инструментом в варианте имеет приоритет |

Пример испытания инструмента: `{"id":"repair", "text":"Настроить механизм", "ability":"intelligence", "tool":"tinker_tools", "difficulty":12}`. Если сам набор обязателен, добавьте его тег в `required_tags`; владение не заменяет наличие предмета.

Скрытность, убеждение, силовое открывание дверей и обнаружение ловушек учитывают соответствующие навыки. Взлом использует отдельное владение отмычками; обезвреживание с инструментом использует его владение. Спасброски и атаки не превращаются в проверки навыков.

Автоматическая проверка: `python -m unittest tests.test_skills tests.test_build_cursor`.
