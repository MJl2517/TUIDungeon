# Справочник игровых тегов

**162** общих признаков, включая состояния, инструменты и станции. Значения генерируются из `tuidungeon/domain/tags.py`.

Правила использования: [gameplay-tags.md](gameplay-tags.md). Разметка всех документов и эффектов: [content-tag-inventory.md](content-tag-inventory.md).

## Материалы и вещества

| Тег | Название | Точное значение |
| --- | --- | --- |
| `wooden` | Деревянный | Существенные деревянные части; не обязательно чистое дерево. |
| `stone` | Каменный | Камень, кладка или каменные части. |
| `metal` | Металлический | Существенные металлические части; не означает проводимость или защиту от огня. |
| `glass` | Стеклянный | Стекло или стекольное сырьё; хрупкость задаётся отдельно. |
| `ceramic` | Керамический | Обожжённая керамика; отличается от сырой глины. |
| `clay` | Глиняный | Необожжённая глина. |
| `cloth` | Тканевый | Ткань или существенные тканевые части. |
| `leather` | Кожаный | Кожа или кожаные части. |
| `paper` | Бумажный / пергамент | Бумага, пергамент и страницы книг. |
| `bone` | Костяной | Кости, рога или костяные части. |
| `organic` | Органический | Биологическое сырьё; не гарантирует съедобность, горючесть или живое существо. |
| `fiber` | Волокнистый | Растительное волокно и волокнистые изделия. |
| `soil` | Земляной | Грунт, который может обрабатываться отдельно от каменного пола. |
| `sand` | Песчаный | Песок; не любое стекольное сырьё. |
| `ice` | Лёд / снег | Замёрзшая вода; не жидкость и не атака холодом. |
| `liquid` | Жидкость | Жидкая среда или содержимое; пустая тара этого признака не имеет. |

| `silver` | Серебро | Явно серебряный материал; не любая светлая вещь. |
| `gold` | Золото | Явно золотой материал; отличается от эффекта выдачи денег. |
| `copper` | Медь | Явно медный материал. |
| `adamantine` | Адамант | Особый материал существующей двери; не синоним неуничтожимости. |

## Природа и реакции

| Тег | Название | Точное значение |
| --- | --- | --- |
| `flammable` | Горючий | Может участвовать в горении; тег не задаёт механику разрушения. |
| `magic` | Магический | Магическая природа источника; книга о магии сама по себе не зачарована. |
| `holy` | Святой | Явно освящённый источник, вода или символ; не всякий алтарь святой. |
| `cursed` | Проклятый | Только явно заданное автором проклятие; никогда не выводится из неизвестности артефакта. |
| `sticky` | Липкий | Паутина, вязкая слизь и явно липкие поверхности. |
| `edible` | Съедобный | Явно предназначено в пищу; не любая органика или гриб. |
| `medicinal` | Лекарственное сырьё | Ингредиент для лечения; не обещает лечение при употреблении. |
| `fuel` | Топливо | Явно топливный ресурс; конкретная станция всё равно проверяет свой fuel_tag. |
| `plants` | Растительность | Растения и растительное сырьё, не деревянная мебель. |
| `fungi` | Грибы | Гриб или грибное сырьё; съедобность задаётся отдельно. |
| `remains` | Останки | Останки существа; состав и однократная добыча задаются отдельно. |
| `rest_spot` | Место для сна | Разложенная лежанка, кровать или спальный мешок для длительного отдыха. |
| `living` | Живое существо | Биологическое существо по природе; текущие HP и смерть проверяются отдельно. |
| `humanoid` | Гуманоид | Тип существа; не материал его оружия. |
| `undead` | Нежить | Тип существа; не накладывает иммунитеты автоматически. |

## Вычисляемые возможности и эффекты

| Тег | Название | Точное значение |
| --- | --- | --- |
| `destructible` | Разрушаемый | Есть DestructionSpec или разрушаемая дверь, либо изнашиваемый предмет. |
| `dismantlable` | Разбираемый | Есть конкретный рецепт разбора; не всякий разрушаемый объект. |
| `movable` | Передвигаемый | Объект разрешает перенос/сдвиг; вес и свободная клетка проверяются действием. |
| `repairable` | Ремонтируемый | Есть исправляемая прочность; фактический ремонт требует повреждения и рецепта. |
| `storage` | Контейнер | Есть StorageSpec; не любой сосуд для жидкости. |
| `vessel` | Сосуд | Есть VesselSpec, ёмкость для жидкости. |
| `heat_safe` | Нагреваемый сосуд | VesselSpec явно допускает нагревание; не выводится из металла. |
| `fragile` | Хрупкий сосуд | VesselSpec явно разрешает разбить при броске. |
| `readable` | Читаемый | Есть ReadingText; изображение свитка само по себе не даёт текст. |
| `recipe_source` | Источник рецептов | Явно выдаёт знания рецептов. |
| `water_source` | Источник воды | Есть WaterSourceSpec; количество и качество определяются им. |
| `station` | Рабочая станция | Есть известный тег станции; исправность проверяется рецептом. |
| `light_source` | Источник света | Есть источник света; горение и оставшееся время проверяются отдельно. |
| `heat` | Источник тепла | Действующий источник тепла; для костра зависит от горения и топлива. |
| `attack` | Атака | Атакующее действие или оружие с уроном. |
| `damage` | Наносит урон | Есть явно заданный урон; величина не кодируется тегом. |
| `healing` | Лечит | Есть эффект лечения; величина и доступность определяются эффектом. |
| `protection` | Защита | Есть свойство базовой КД или бонуса КД. |
| `condition` | Накладывает состояние | Есть эффект condition; конкретное состояние отдельным признаком. |
| `applies_poison` | Накладывает отравление | Есть condition poisoned; ядовитый урон сам по себе не накладывает отравление. |
| `applies_fear` | Вызывает страх | Есть condition frightened. |
| `applies_persuasion` | Убеждает | Есть condition persuaded. |
| `detect_magic` | Обнаруживает магию | Есть condition detect_magic; радиус и длительность в эффекте. |
| `antidote` | Противоядие | Средство явно снимает отравление. |
| `knowledge` | Даёт знание | Есть зарегистрированный эффект learn_recipe. |
| `reward` | Выдаёт награду | Есть эффект gold или experience; не материал цели. |
| `dodge` | Уклонение | Действие dodge; не обещает неуязвимость. |
| `stealth` | Скрытность | Действие stealth; успех определяет проверка. |
| `influence` | Социальное воздействие | Действие influence; не психический урон. |
