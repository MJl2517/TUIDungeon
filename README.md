# TUI Dungeon + Studio

Фэнтезийный dungeon crawler с терминальной игрой и локальной браузерной мастерской.
Графика, механики и подземелья хранятся в JSON-пакетах. Браузер и TUI используют
один Python-движок, одинаковые проверки, ресурсы героя и последствия действий.

## Установка и запуск

Нужны **Python 3.11+**, **Node.js 20.19+**, npm и современный браузер.
Для терминальной игры нужны Linux/macOS, `curses`, UTF-8 и окно от **80×24**.

```bash
./setup.sh                     # Один раз: Python-зависимости, npm ci, сборка сайта
./run.sh                       # Терминальная игра
./run.sh --studio              # Студия: сервер + открытие браузера
./run.sh --map base:crypt       # Игра на карте «Склеп забытых»
./run.sh --map base:crypt --seed 42
./run.sh --test-map base:crypt  # Сразу на карту с готовым героем, без меню
```

Студия доступна по **http://127.0.0.1:8765**. Она работает только на локальном
адресе; Ctrl+C останавливает сервер. После установки интернет не нужен:
интерфейс, шрифты, палитры и контент находятся локально.

```bash
./run.sh --studio --no-browser --port 8766
./run.sh --symbols unicode      # Unicode-рамки и стиль исходной учебной карты
./run.sh --validate-content     # Проверка всех пакетов без терминала
./run.sh --packs-dir ./packs    # Другая папка пакетов
```

`run.sh` выбирает `.venv/bin/python` и работает при запуске из другой папки.
Для быстрого теста используйте `./run.sh --test-map base:crypt --seed 42`.
Флаг без аргумента тестирует карту из `--map` (по умолчанию `base:dungeon`):
`./run.sh --map base:crypt --test-map`. Тестовый герой — человек-воин первого
уровня с базовыми характеристиками СИЛ 14, ЛОВ 12, ТЕЛ 13, ИНТ 10, МДР 10,
ХАР 8; расовые бонусы и стартовое снаряжение применяются обычными правилами.
Если в каталоге нет человека или воина, выбирается первая доступная раса/класс.
Каждый запуск создаёт новую сессию; исходные файлы карты не изменяются.

Прямой запуск: `.venv/bin/python -m tuidungeon`. Для разработки интерфейса
оставьте API запущенным и выполните `npm run dev --prefix studio`; после изменений
пересоберите его командой `npm run build --prefix studio`.

## Что можно делать в студии

- Рисовать ASCII/Unicode-арты кистью, ластиком, заливкой, линиями, рамками и текстом;
  выделять, переносить, копировать и вставлять области. Есть 256 цветов символа
  и фона, прозрачность, слои, блокировка, видимость, порядок, сетка и масштаб.
- Импортировать TXT и JSON, сохранять редактируемые слои в `*.art.json`,
  экспортировать TXT/JSON. Недопустимые символы подсвечиваются с координатами.
- Создавать монстров, предметы, заклинания, действия, классы, расы, предыстории,
  испытания, тайлы, ловушки и точки интереса через формы общих Python-схем.
  Ссылки выбираются из библиотеки; рисунок и характеристики видны в предпросмотре.
- Рисовать подземелья тайлами и готовыми артами, отдельно редактировать маски
  движения и обзора, размещать существ, предметы, ловушки, события, старт и переходы.
  Инспектор показывает содержимое клетки; недостижимые области отмечаются предупреждением.
- Тестировать сохранённую карту на Python-движке с выбранными характеристиками
  героя и seed: движение, стены, ловушки, события, отдых, журнал бросков и эффектов.
  Перезапуск восстанавливает исходную сессию и не изменяет файлы карты.
- Проверять отдельные действия монстра в песочнице, подключать новые пакеты,
  искать объекты, дублировать шаблоны и смотреть места их использования.

**Ctrl+S** сохраняет документ, **Ctrl+Z / Ctrl+Shift+Z** отменяет/возвращает
изменения редактора. Во время ввода текста действуют обычные горячие клавиши
поля. При смене документа студия предупреждает о несохранённом черновике.
Внешние изменения файлов обнаруживаются при обновлении библиотеки; устаревший
черновик не перезаписывает новый файл. ID фиксируется при создании документа;
для другого ID используйте дублирование.

## Управление игрой

При запуске открывается главное меню без рамок: **Новая игра**, **Загрузить**,
**Настройки**, **Справка**, **Выйти**. Выбранный пункт выделен жирным и скобками
`[ ... ]`. Стрелки вверх/вниз или W/S выбирают пункт, Enter открывает его;
цифры 1–5 сразу открывают соответствующий пункт. Backspace/Esc возвращает из
настроек и справки, а также из первого шага создания героя в главное меню.
В настройках можно выбрать ASCII или Unicode (1/2 либо стрелками); выбор действует
до закрытия приложения. «Загрузить» продолжает быстрое сохранение; если файла нет
или он повреждён, выводится сообщение.

Во время исследования действия персонажа и управление игрой разделены.
Панель показывает доступные команды текущего уровня; **Backspace/Esc** возвращает
на уровень выше. Вложенные меню приостанавливают перемещение персонажа.

| Клавиша | Действие |
| --- | --- |
| WASD | Перемещение по четырём направлениям |
| ← / ↑, → / ↓, Tab | Инвентарь / заклинания в правой панели |
| 1 | Осмотр: мигающий курсор X, WASD/стрелки двигают его, Enter открывает карточку клетки |
| Enter рядом с точкой интереса | Взаимодействие; затем цифра варианта |
| 2 | Лист персонажа: характеристики, снаряжение, заклинания |
| [ / ] | Предыдущий / следующий раздел листа |
| PgUp / PgDn | Страницы списка или текста |
| 1–6 в разделе снаряжения | Карточка предмета; 1 — надеть/снять, 2 — применить |
| 1–6 в разделе заклинаний | Применить заклинание, при необходимости выбрать живую цель |
| 3 → 1 | Включить/выключить режим «Красться» |
| 3 → 2 | Магия: выбор заклинания и цели |
| 3 → 3 | Ждать одну минуту |
| 4 → 1 | Короткий отдых: час, восстановление до половины максимального HP |
| 4 → 2 | Долгий отдых: восемь часов, полное восстановление HP и магии |
| Alt+1 / Alt+2 | Быстрое сохранение / загрузка |
| Alt+3 / Alt+4 / Alt+5 | Справка / меню выхода / настройки |
| M | Переключить панель действий на мета-действия и обратно |
| Q | Меню выхода: 1 — главное меню, 2 — закрыть игру |
| Backspace / Esc | Назад |

В терминалах Kitty/WezTerm с расширенным клавиатурным протоколом панель меняется
при нажатии Alt и возвращается при отпускании. Обычные терминалы не передают
отдельные события модификаторов: там работают **Alt+цифра** и переключатель **M**.
В WezTerm требуется [enable_kitty_keyboard = true](https://wezterm.org/config/lua/config/enable_kitty_keyboard.html).
Подробности формата ввода: [протокол Kitty](https://sw.kovidgoyal.net/kitty/keyboard-protocol/).
Если терминал перехватывает сочетание Alt, используйте M.

Команды листа персонажа расположены внизу, названия характеристик и ключевые поля
выделены жирным. Осмотр не передвигает героя, не раскрывает скрытые несработавшие
ловушки и не расходует время. В карточке клетки могут отображаться сразу несколько
объектов. Обзор карты пока полностью открыт; дальность заклинаний ещё не ограничивается.

Быстрое сохранение хранится в `saves/quicksave.json`; каждый вызов заменяет этот
слот атомарно. Другой файл задаётся через `--save-file /path/to/slot.json`.
Сохраняются герой, предметы и ресурсы, посещённые уровни, ловушки, испытания,
существа, игровое время, скрытность и состояние генератора бросков. JSON не содержит
исполняемого кода. Изменённая после сохранения карта не загружается; используйте
тот же набор пакетов. Ошибка загрузки оставляет текущую игру доступной.

Четыре панели: карта/персонаж, действия, инвентарь/заклинания, время/средства.
Камера следует за героем. Изменение размера пересчитывает панели; при окне меньше
80×24 игровые команды приостанавливаются. Выход и Ctrl+C восстанавливают терминал.
Цвета подстраиваются под доступную палитру терминала; без цвета остаются символы.

## Принятые правила

Создание героя: раса → класс → шесть бросков **4d6 без меньшего** → ручное
распределение → подтверждение. До начала игры можно перебрасывать набор.
Модификатор — `(характеристика − 10) // 2`; проверка — `d20 + модификатор >= СЛ`.
Преимущество/помеха выбирают больший/меньший из двух d20 и взаимно отменяются.
Автоматических критических успехов/провалов пока нет.

Человек получает +1 ко всем характеристикам; дварф — +1 максимального HP за
уровень; эльф — отдельное применение «Обнаружения магии» раз за отдых.
Начальный уровень — 1. HP: воин `10 + мод. ТЕЛ`, плут `8 + мод. ТЕЛ`,
волшебник `6 + мод. ТЕЛ`, затем расовый бонус, минимум 1.
Волшебник знает «Волшебную стрелу» и «Обнаружение магии» и имеет две ячейки
первого уровня. Расовое применение и классовые ячейки независимы.
Стартовое снаряжение соответствует классу; просмотр инвентаря не расходует время.

Начало: день 1, 08:00, 0 золота/опыта. Обычный шаг и ожидание — ход и минута; стена,
живое существо, меню и вкладки времени не расходуют. Ловушка проверяется при
входе на клетку и по умолчанию срабатывает однажды. С точкой интереса можно
взаимодействовать со своей или соседней по стороне клетки; состоявшийся выбор
расходует время варианта. Одноразовое испытание завершается и при провале.
Режим «Красться» удваивает время шага (эффективная скорость 1/2), даёт
преимущество против ловушек и на бросок инициативы будущих столкновений. Переключение
режима не расходует ход. Короткий отдых длится час и лечит на `max(1, max_hp // 2)`
без восстановления магии; пула кубиков хитов пока нет. Долгий отдых восстанавливает
HP, ячейки и расовые применения, очищает состояния,
но не чинит предметы и не восполняет их заряды. Оба отдыха выключают скрытность.
Применение предмета, заклинания, надевание/снятие снаряжения расходует ход и минуту
при успешном выполнении. Классовая и расовая магия выбираются отдельно, даже если
это одно и то же заклинание. Переход на другую карту
сохраняет героя, время и состояние уже посещённых уровней.

Для создания и исследования используются отдельные потоки случайности от
одного `--seed`: перебросы характеристик не смещают броски ловушек. Для точного
сравнения браузера и TUI задайте одинаковые базовые характеристики, расу, класс,
seed и последовательность игровых команд.

Правила упрощены и вдохновлены D&D. Полный JRPG-бой, AI, анимация, случайный лут,
прокачка и глобальная карта остаются следующими этапами.
Инициатива со скрытностью готова для будущего режима боя; столкновения пока не запускают бой.

## Структура

```text
tuidungeon/
  domain/          # Персонажи, предметы, действия, эффекты, испытания и plugins/
  application/     # Движок, создание героя и фабрики сессий
  world/           # Геометрия, время и экземпляры размещений уровня
  content/         # Pydantic-схемы, пакеты, ссылки, миграция, старый загрузчик
  presentation/    # Композиция цветных клеток, TUI и старые TXT-арты
  tooling/         # FastAPI, тестовые сессии и песочница
studio/src/        # React + TypeScript: формы, графика, карта и playtest
packs/base/        # manifest.json + 13 категорий JSON-контента
scripts/           # Проверка студии в настоящем браузере
docs/              # Контракты и примеры расширения
tests/             # Правила, пакеты, API, сравнение клиентов и настоящий PTY
```

Определения и состояние экземпляров разделены. Объекты создают фабрики;
монстры и предметы имеют уникальные `instance_id`. Студия берёт формы из
JSON Schema, а параметры новых зарегистрированных эффектов — из общего реестра.
Исходные `tuidungeon/content/data` и TXT-арты сохранены; `--content-dir` оставлен
для совместимости со старым форматом.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
npm test --prefix studio
npm run format:check --prefix studio
npm run build --prefix studio
./run.sh --validate-content
```

Дополнительная проверка в Chrome/Chromium выполняется на временных пакетах:

```bash
.venv/bin/pip install -r requirements-browser.txt
# Если системного Chrome нет: .venv/bin/playwright install chromium
.venv/bin/python scripts/check_studio_browser.py
```

Она проверяет создание/повторное открытие многослойного арта, undo/redo,
форму монстра и особое действие, маски/размещения карты и playtest с перезапуском.
