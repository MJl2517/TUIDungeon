# TUI Dungeon + Studio

Фэнтезийный dungeon crawler с игровым окном python-tcod и локальной браузерной мастерской.
Графика, механики и подземелья хранятся в JSON-пакетах. Браузер и TUI используют
один Python-движок, одинаковые проверки, ресурсы героя и последствия действий.

[Ревизия контента: единые шаблоны, перенос старых карт и сквозной поиск](docs/content-revision.md).

## Установка и запуск

Нужны **Python 3.11+**, **Node.js 20.19+**, npm и современный браузер.
Поддерживаются Windows, Linux и macOS. Игра открывает отдельное окно SDL с общей палитрой и встроенными шрифтами
на всех платформах. Терминальный режим доступен через `--terminal` (от **80×24**).

Linux/macOS:

```bash
./setup.sh                     # Один раз: Python-зависимости, npm ci, сборка сайта
./run.sh                       # Игровое окно tcod
./run.sh --studio              # Студия: сервер + открытие браузера
./run.sh --map base:crypt       # Игра на карте «Склеп забытых»
./run.sh --map base:crypt --seed 42
./run.sh --test-map base:crypt  # Сразу на карту с готовым героем, без меню
./run.sh --test-wizard base:crypt  # Волшебник со всеми заклинаниями и заговорами
```

Windows (PowerShell; в CMD можно опустить `.\`):

```powershell
.\setup.bat                     # Один раз: зависимости и сборка сайта
.\run.bat                       # Игровое окно tcod
.\studio.bat                    # Локальная студия
.\run.bat --test-map base:crypt --seed 42
.\run.bat --test-wizard base:crypt --seed 42
.\run.bat --validate-content
```

На Windows установите обычный CPython x64 и Node.js, доступные через PATH.
`setup.bat` использует `py -3` или `python` и автоматически устанавливает
[windows-curses](https://pypi.org/project/windows-curses/2.4.2/);
Linux/macOS используют встроенный модуль `curses` для запасного режима.
Обычный запуск работает через [python-tcod](https://python-tcod.readthedocs.io/) и SDL,
не зависит от консоли и её шрифтов. **F11** переключает полный экран; размер окна
меняет число клеток интерфейса. Карта рисуется отдельно квадратными клетками,
камера следует за героем (в осмотре и броске — за курсором). `+` / `-` и колесо
мыши меняют только масштаб карты; размер текста интерфейса сохраняется.
Для Linux нужен графический сеанс (X11 или Wayland).
Управление буквенными клавишами работает и при русской раскладке; поиск принимает
кириллицу. DejaVu и Noto находятся в `assets/fonts/` вместе с лицензиями.
Обновить Python-зависимости существующей установки:
`.venv/bin/python -m pip install -r requirements.txt` (Linux/macOS) или
`.\.venv\Scripts\python.exe -m pip install -r requirements.txt` (Windows).
Вернуться к терминалу: `./run.sh --terminal` или `.\run.bat --terminal`.
Этот режим использует шрифт терминала.

Студия доступна по **http://127.0.0.1:8765**. Она работает только на локальном
адресе; Ctrl+C останавливает сервер. После установки интернет не нужен:
интерфейс, шрифты, палитры и контент находятся локально.

```bash
./run.sh --studio --no-browser --port 8766
./run.sh --symbols unicode      # Unicode-рамки и стиль исходной учебной карты
./run.sh --validate-content     # Проверка всех пакетов без открытия окна
./run.sh --packs-dir ./packs    # Другая папка пакетов
```

Скрипты выбирают Python из `.venv` (`bin/python` на Linux/macOS,
`Scripts\python.exe` на Windows), работают при запуске из другой папки и
передают все параметры приложению. Окружение `.venv` и `studio/node_modules`
создавайте на каждой платформе её скриптом установки, не переносите их между ОС.
Пакеты контента и JSON-сохранения можно переносить.
Для быстрого теста используйте `./run.sh --test-map base:crypt --seed 42`.
Флаг без аргумента тестирует карту из `--map` (по умолчанию `base:dungeon`):
`./run.sh --map base:crypt --test-map`. Тестовый герой — человек-воин первого
уровня с базовыми характеристиками СИЛ 14, ЛОВ 12, ТЕЛ 13, ИНТ 10, МДР 10,
ХАР 8; расовые бонусы и стартовое снаряжение применяются обычными правилами.
Если в каталоге нет человека или воина, выбирается первая доступная раса/класс.
Каждый запуск создаёт новую сессию; исходные файлы карты не изменяются.

Для проверки магии: `./run.sh --test-wizard base:crypt` (Windows:
`.\run.bat --test-wizard base:crypt`). Это человек-волшебник первого уровня
с базовым интеллектом 18, стартовым снаряжением класса, всеми заклинаниями
и заговорами из подключённых пакетов и 10 ячейками каждого представленного
уровня. Заговоры используют обычный общий запас; долгий отдых восстанавливает
ресурсы. Сохранение и загрузка сохраняют тестовый профиль и остаток ресурсов.
Без аргумента используется `--map` или `base:dungeon`; `--terminal` включает TUI.
Например: `./run.sh --terminal --map base:crypt --test-wizard --seed 42`.
Магия открывается через **3 → 2**; боевые заклинания по-прежнему требуют
боевого режима и не получают новых эффектов от тестового запуска.
Флаги `--test-map` и `--test-wizard` выбираются по отдельности.
Другой готовый класс: `./run.sh --test-map base:crypt --test-class base:rogue`.
В студии класс выбирается в списке рядом с кнопкой «В игровом окне»;
список включает классы всех подключённых пакетов. Выбор волшебника использует
тот же профиль со всеми заклинаниями, что и `--test-wizard`.

Прямой запуск: `.venv/bin/python -X utf8 -m tuidungeon` на Linux/macOS или
`.\.venv\Scripts\python.exe -X utf8 -m tuidungeon` на Windows.
Для разработки интерфейса
оставьте API запущенным и выполните `npm run dev --prefix studio`; после изменений
пересоберите его командой `npm run build --prefix studio`.

## Что можно делать в студии

- Рисовать ASCII/Unicode-арты кистью, ластиком, заливкой, линиями, рамками и текстом;
  выделять, переносить, копировать и вставлять области. Есть 256 цветов символа
  и фона, прозрачность, слои, блокировка, видимость, порядок, сетка и масштаб.
- Импортировать TXT и JSON, сохранять редактируемые слои в `*.art.json`,
  экспортировать TXT/JSON. Недопустимые символы подсвечиваются с координатами.
- Создавать монстров, предметы, заклинания, действия, классы, расы, предыстории,
  испытания, тайлы, ловушки и точки интереса через формы общих Python-схем.
  Ссылки выбираются из библиотеки; рисунок и характеристики видны в предпросмотре.
- Рисовать подземелья тайлами и готовыми артами, отдельно редактировать маски
  движения и обзора, размещать существ, предметы, ловушки, события, старт и переходы.
  Инспектор показывает содержимое клетки; недостижимые области отмечаются предупреждением.
  В правой палитре 434 кисти, из них 196 добавляют двери, свет, ловушки, взаимодействия,
  предметы или переходы. Есть категории, поиск, фильтры и сортировка.
  ПКМ перемещает карту, I включает пипетку, Ctrl + колесо меняет масштаб.
  Студия открывается с главной страницей; одна навигационная панель сворачивается.
  [Управление редактором](docs/studio.md#главная-и-редактор-карты), [каталог кистей](docs/tiles.md).
- Тестировать сохранённую карту на Python-движке с выбранными характеристиками
  героя и seed: движение, стены, ловушки, события, отдых, журнал бросков и эффектов.
  Перезапуск восстанавливает исходную сессию и не изменяет файлы карты.
- Проверять отдельные действия монстра в песочнице, подключать новые пакеты,
  искать объекты, дублировать шаблоны и смотреть места их использования.

**Ctrl+S** сохраняет документ, **Ctrl+Z / Ctrl+Shift+Z** отменяет/возвращает
изменения редактора. Во время ввода текста действуют обычные горячие клавиши
поля. При смене документа студия предупреждает о несохранённом черновике.
Внешние изменения файлов обнаруживаются при обновлении библиотеки; устаревший
черновик не перезаписывает новый файл. ID фиксируется при создании документа;
для другого ID используйте дублирование.

## Управление игрой

При запуске открывается главное меню без рамок: **Новая игра**, **Загрузить**,
**Настройки**, **Справка**, **Выйти**. Выбранный пункт выделен жирным и скобками
`[ ... ]`. Стрелки вверх/вниз или W/S выбирают пункт, Enter открывает его;
цифры 1–5 сразу открывают соответствующий пункт. Backspace/Esc возвращает из
настроек и справки, а также из первого шага создания героя в главное меню.
В настройках можно выбрать ASCII или Unicode (1/2 либо стрелками); выбор действует
до закрытия приложения. «Загрузить» продолжает быстрое сохранение; если файла нет
или он повреждён, выводится сообщение.

Во время исследования действия персонажа и управление игрой разделены.
Панель показывает доступные команды текущего уровня; **Backspace/Esc** возвращает
на уровень выше. Вложенные меню приостанавливают перемещение персонажа.

| Клавиша | Действие |
| --- | --- |
| WASD | Перемещение по четырём направлениям |
| ← / →, Tab в исследовании | По кругу: инвентарь / заклинания / состояния в правой панели |
| ↑ / ↓, Enter в инвентаре | Выбор предмета и его действий; заголовки сворачивают категории |
| F в инвентаре | Поиск по названию, описанию, типу или тегам; Enter принимает фильтр, Esc отменяет |
| I | Фокус правого инвентаря; Backspace возвращает управление карте |
| G | Подобрать первый предмет под ногами |
| 1 / E | Осмотр: мигающий курсор X, WASD/стрелки двигают его, Enter открывает карточку клетки |
| Enter рядом с точкой интереса | Взаимодействие; затем цифра варианта |
| 2 | Лист персонажа: характеристики, снаряжение, заклинания |
| ← / → в персонаже | Страницы: лист персонажа, снаряжение, заклинания; [/ ] также работают |
| PgUp / PgDn | Страницы списка или текста |
| 1 / 2 / 3 / 4 после выбора предмета | Использовать / осмотреть / бросить / положить на землю |
| 1–6 в разделе заклинаний | Применить заклинание, при необходимости выбрать живую цель |
| Z / 3 → 1 | Включить/выключить скрытность; герой серый, в интерфейсе виден режим |
| 3 → 2 | Магия: выбор заклинания и цели |
| 3 → 3 | Ждать одну минуту |
| 3 → 4 при активной Волшебной руке | Дистанционное взаимодействие: клетка → Enter |
| 4 → 1 | Короткий отдых: час, до половины максимального HP и заговоры +модификатор |
| 4 → 2 | Долгий отдых: восемь часов, полное восстановление HP и магии |
| M | Всплывающее игровое меню: сохранить, загрузить, справка, выход, настройки |
| ↑ / ↓ и Enter в диалоге | Выбрать и выполнить действие; цифры также работают |
| Щелчок по предмету в правой панели | Открыть окно действий с предметом (в режиме tcod) |
| Q | Меню выхода: 1 — главное меню, 2 — закрыть игру |
| Backspace / Esc | Назад |

Меню открывается клавишей **M** на Windows и Linux; Alt не используется.
Действия с предметами, взаимодействия с окружением, осмотр, отдых и магия
открываются в окнах поверх карты. **Esc** или **Backspace** возвращает назад;
**M** закрывает игровое меню и возвращает к предыдущему окну.
Просмотр диалогов не расходует время. Поиск инвентаря продолжает принимать
буквы M и Q как текст. В окне tcod пункты диалогов можно выбирать мышью.

Команды листа персонажа расположены внизу, названия характеристик и ключевые поля
выделены жирным. Пока открыт персонаж, правая панель показывает пустой раздел
«Квесты»; стрелки управляют страницами и списками персонажа. Backspace закрывает
страницу персонажа. В инвентаре четыре категории: вооружение, доспехи, расходники,
инструменты. Полоса внизу показывает общий вес, предел переноски и перегрузку.
Перед названием экипируемой вещи: `[*]` — надето, `[ ]` — снято.
Поиск и навигация одинаково работают в обеих панелях и не расходуют время.
При вводе поиска буквенные и цифровые команды игры не срабатывают.

В листе персонажа рядом с характеристиками показаны состояния. Тот же список
доступен третьей вкладкой правой панели при исследовании: ослепление, истощение,
жажда, голод, отравление, благословление, оглушение и испуг. Значение `--`
обозначает плейсхолдер; отслеживание этих показателей и их эффекты пока не добавлены.

Enter открывает действия выбранного предмета. «Использовать» надевает/снимает
предмет со слотом, а для остальных применяет активные эффекты. Осмотр открывает
окно поверх панелей с описанием, типом, весом, КД, уроном, стойкостью, зарядами,
тегами, свойствами и помощью в проверках; ↑↓/PgUp/PgDn перелистывают текст.
При броске WASD/стрелки выбирают клетку, Enter подтверждает, Backspace отменяет.
Дальность — `max(0, модификатор СИЛ + 1)` по расстоянию в четырёх направлениях.
Стены и занятые живыми существами клетки запрещены; бросок пока перемещает
предмет без нанесения урона. Положить можно на свою клетку. Бросок, укладывание
и подбор расходуют один ход и минуту; отмена и неудача — ничего. Вещи на земле
сохраняют свою стойкость и заряды и записываются в сохранение.
Рядом с точкой интереса Enter взаимодействует с ней; ↑↓ или I переводят Enter
на выбор предмета, WASD/Backspace возвращают управление карте.

Осмотр не передвигает героя, не раскрывает скрытые несработавшие
ловушки и не расходует время. В карточке клетки могут отображаться сразу несколько
объектов. Обзор зависит от света и преград; заклинание можно направить только на видимую цель.
Отдельная дальность заклинаний пока не ограничивается.

Быстрое сохранение хранится в `saves/quicksave.json`; каждый вызов заменяет этот
слот атомарно. Другой файл задаётся через `--save-file /path/to/slot.json`.
Сохраняются герой, предметы и ресурсы, посещённые уровни, ловушки, испытания,
существа, игровое время, скрытность и состояние генератора бросков. JSON не содержит
исполняемого кода. Изменённая после сохранения карта не загружается; используйте
тот же набор пакетов. Ошибка загрузки оставляет текущую игру доступной.

Четыре панели: карта/персонаж, действия, инвентарь/заклинания, время/средства.
Камера следует за героем. Изменение размера пересчитывает панели; при окне меньше
80×24 игровые команды приостанавливаются. Выход и Ctrl+C восстанавливают терминал.
Цвета подстраиваются под доступную палитру терминала; без цвета остаются символы.

## Освещение

Подземелье и склеп по умолчанию тёмные. Без света видны герой и соседние клетки
по четырём направлениям. Свет движется вместе с героем; стены и независимая маска
`blocks_sight` перекрывают освещение и обзор. Невидимые клетки пусты, полумрак
показывается приглушённым цветом. Осмотр клетки сообщает: яркий свет, тусклый
свет или полная тьма. Для тусклого света показана подсказка: −5 к пассивным
и активным проверкам внимательности и анализа. Видимый символ героя и соседние
клетки без источника света помогают перемещаться, но не создают освещение.
На уже посещённых клетках память карты пока не ведётся.

Каждый класс начинает с факелом, лампой и одной порцией масла, пока без экипировки:

| Предмет | Горение | Радиус яркого / всего света |
| --- | --- | --- |
| Факел | 60 игровых минут; после выгорания нужен новый | 3 / 6 клеток |
| Масляная лампа | Одна порция масла на 60 минут | 4 / 8 клеток |

В инвентаре найдите предмет через **F**, выберите **Enter**, затем **1**:
взять и зажечь или снять и погасить. У героя две руки. Оружие и щит занимают по
одной; двуручное снаряжение — две. Воину сначала нужно снять щит или оружие.
Количество занятых рук видно над полосой нагрузки. Остаток горения показывается
над картой и в осмотре предмета. Пустая лампа расходует масло автоматически при
экипировке; если руки заняты или масла нет, ничего не расходуется.

Снятие гасит источник и сохраняет остаток топлива; повторное зажигание непустой
лампы не расходует новое масло. Сгоревший факел исчезает из инвентаря или с земли и освобождает руку.
Лампа без масла остаётся в руке, пока её не снять. Зажигание и смена снаряжения стоят одну игровую минуту, включая горение
в эту минуту. Шаг в скрытности расходует две минуты, ожидание — одну, короткий
отдых — 60, долгий — 480. Меню и неудачные действия не расходуют топливо.
Брошенный или положенный горящий предмет продолжает освещать клетку и гореть;
подбор в рюкзак гасит его. Топливо сохраняется в сохранениях и расходуется даже
у источников на ранее посещённых картах.

В студии для карты доступны **темнота / полумрак / яркий свет** и слой
**«Источники света»** для стационарных огней с отдельными радиусами. Выберите
огонь инструментом выбора, чтобы настроить его или выключить. Маска преград
обзору рисуется отдельно от проходимости. В тесте карты есть кнопки экипировки
снаряжения; освещение, масло и время рассчитывает тот же Python-движок.

Остаток прочности отображается рядом с названием предмета: `(6/10)`,
в правом инвентаре и на странице снаряжения. Без прочности счётчик не выводится.

## Принятые правила

Создание героя: раса → класс → предыстория → шесть бросков **4d6 без меньшего**
→ ручное распределение → подтверждение. У волшебника перед подтверждением
есть дополнительный шаг: выбор **трёх заговоров**.
**WASD/стрелки** выбирают кнопку, **Enter** подтверждает; выбранная кнопка
выделена жирным и `[скобками]`. **Backspace** или кнопка «Назад» возвращают
на предыдущий шаг, а при распределении отменяют последнее назначение.
Цифры остаются быстрым способом выбора. **H** перелистывает длинные подсказки
справа; **PgUp/PgDn** переключают страницы вариантов.

У каждого броска показаны все четыре кубика; один отброшенный заключён в круглые
скобки. При распределении справа объясняется характеристика и её бонус, а
уже использованные результаты исчезают из кнопок. Одинаковые числа можно
назначить разным характеристикам: это разные броски. Навигация назад сохраняет
набор; кнопка переброса заменяет все шесть чисел и очищает назначения.
Перед началом показан итоговый лист с расовыми бонусами, предысторией и тегом.

| Класс | Предыстория | Дополнительные вещи | Навыки (плейсхолдеры) | Тег |
| --- | --- | --- | --- | --- |
| Плут | Вор | Ломик, верёвка | Ловкость рук, скрытность | `thief` |
| Волшебник | Мудрец | Чернила и перо, пергамент | Магия, история | `sage` |
| Воин | Солдат | Дорожный паёк, спальный мешок | Атлетика, запугивание | `soldier` |

Предыстории задают список доступных классов в JSON. Для пользовательского класса
без привязанных предысторий доступно продолжение без неё. Старые «Учёный» и
«Странник» сохранены в библиотеке и доступны API/студии. Навыки пока только
отображаются и не дают бонусов к проверкам. Тег предыстории открывает особые
варианты событий: пример уже есть у алтаря в склепе. Такие варианты задаются
полем `visible_tags`; герой без нужных тегов их не видит и не может выполнить.

Модификатор — `(характеристика − 10) // 2`; проверка — `d20 + модификатор >= СЛ`.
Преимущество/помеха выбирают больший/меньший из двух d20 и взаимно отменяются.
Автоматических критических успехов/провалов пока нет.

Человек получает +1 ко всем характеристикам; дварф — +1 максимального HP за
уровень; эльф — отдельное применение «Обнаружения магии» раз за отдых.
Начальный уровень — 1. HP: воин `10 + мод. ТЕЛ`, плут `8 + мод. ТЕЛ`,
волшебник `6 + мод. ТЕЛ`, затем расовый бонус, минимум 1.
Волшебник знает «Волшебную стрелу» и «Обнаружение магии» и имеет две ячейки
первого уровня, а также три выбранных заговора. Их общий запас равен
значению интеллекта (INT 16 → 16 зарядов); каждое применение стоит один заряд.
Расовое применение, классовые ячейки и заряды заговоров независимы.
Правила и ограничения: [заговоры и концентрация](docs/cantrips.md).
Стартовое снаряжение соответствует классу; просмотр инвентаря не расходует время.

Начало: день 1, 08:00, 0 золота/опыта. Обычный шаг и ожидание — ход и минута; стена,
живое существо, меню и вкладки времени не расходуют. Ловушка проверяется при
входе на клетку и по умолчанию срабатывает однажды. С точкой интереса можно
взаимодействовать со своей или соседней по стороне клетки; состоявшийся выбор
расходует время варианта. Одноразовое испытание завершается и при провале.
Режим «Красться» удваивает время шага (эффективная скорость 1/2), даёт
преимущество против ловушек и на бросок инициативы будущих столкновений. Переключение
режима не расходует ход. Короткий отдых длится час и лечит на `max(1, max_hp // 2)`
и восстанавливает `max(0, модификатор заклинательской характеристики)` зарядов
заговоров, но не ячейки; пула кубиков хитов пока нет. Долгий отдых восстанавливает
HP, ячейки, заговоры и расовые применения, очищает состояния,
но не чинит предметы и не восполняет их заряды. Оба отдыха выключают скрытность, прекращают концентрацию и временную магию.
Применение предмета, заклинания, надевание/снятие снаряжения расходует ход и минуту
при успешном выполнении. Классовая и расовая магия выбираются отдельно, даже если
это одно и то же заклинание. Переход на другую карту
сохраняет героя, время и состояние уже посещённых уровней.

Для создания и исследования используются отдельные потоки случайности от
одного `--seed`: перебросы характеристик не смещают броски ловушек. Для точного
сравнения браузера и TUI задайте одинаковые базовые характеристики, расу, класс,
seed и последовательность игровых команд.

Правила упрощены и вдохновлены D&D. Полный JRPG-бой, AI, анимация, случайный лут,
прокачка и глобальная карта остаются следующими этапами.
Инициатива со скрытностью готова для будущего режима боя; столкновения пока не запускают бой.

## Структура

```text
tuidungeon/
  domain/          # Персонажи, предметы, действия, эффекты, испытания и plugins/
  application/     # Движок, создание героя и фабрики сессий
  world/           # Геометрия, время и экземпляры размещений уровня
  content/         # Pydantic-схемы, пакеты, ссылки, миграция, старый загрузчик
  presentation/    # Композиция цветных клеток, TUI и старые TXT-арты
  tooling/         # FastAPI, тестовые сессии и песочница
studio/src/        # React + TypeScript: формы, графика, карта и playtest
packs/base/        # manifest.json + 13 категорий JSON-контента
scripts/           # Проверка студии в настоящем браузере
docs/              # Контракты и примеры расширения
tests/             # Правила, пакеты, API, сравнение клиентов и настоящий PTY
```

Определения и состояние экземпляров разделены. Объекты создают фабрики;
монстры и предметы имеют уникальные `instance_id`. Студия берёт формы из
JSON Schema, а параметры новых зарегистрированных эффектов — из общего реестра.
Исходные `tuidungeon/content/data` и TXT-арты сохранены; `--content-dir` оставлен
для совместимости со старым форматом.

## Проверки

```bash
.venv/bin/python -X utf8 -m unittest discover -s tests -v
npm test --prefix studio
npm run format:check --prefix studio
npm run build --prefix studio
./run.sh --validate-content
```

На Windows замените `.venv/bin/python` на `.venv\Scripts\python.exe`,
а `./run.sh` — на `.\run.bat`. Проверки Unix-терминала через PTY на Windows
пропускаются; тесты движка, API, сохранений и обработки клавиш выполняются.

Дополнительная проверка в Chrome/Chromium выполняется на временных пакетах:

```bash
.venv/bin/pip install -r requirements-browser.txt
# Если системного Chrome нет: .venv/bin/playwright install chromium
.venv/bin/python -X utf8 scripts/check_studio_browser.py
```

Она проверяет создание/повторное открытие многослойного арта, undo/redo,
форму монстра и особое действие, маски/размещения карты и playtest с перезапуском.

Свойства объектов на карте настраиваются через **Выделение (V)** → объект →
**«Клетка» → «Свойства экземпляра»**. Для дверей достаточно пяти материалов;
замок, состояние и хиты задаются индивидуально. Такой же инспектор работает
для ловушек, предметов, существ и текстовых испытаний.
[Руководство и формат данных](docs/instance-properties.md).

Поджог: в меню кремня и кресала, горящего факела или огненного оружия выберите **5**, затем соседнюю клетку и Enter. Масло используется и для ламп, и для броска на клетку. Правила огня, кислоты и износа оружия: [двери и покрытия](docs/doors.md#масло-и-поджог).

Теги материалов: **Горючий** (`flammable`) и **Деревянный** (`wooden`).
В студии они переключаются флажками; в игре видны при осмотре и доступны
для поиска в инвентаре. [Правила материалов](docs/materials.md).

Контейнеры (`storage`): Enter рядом с сундуком, мешком, ящиком или шкафом
открывает две колонки. Tab / ←→ выбирают колонку, ↑↓ — вещь, Enter / F5 переносят,
Backspace закрывает. Для группы предметов появляется ползунок количества.
Личные контейнеры разрешают складывать вещи и не обновляются; лутовые — только
забирать. Вместимость по умолчанию 1000 кг. Настройка в студии и формат данных:
[контейнеры](docs/storage.md). Полигон всех контейнеров:
`./run.sh --test-map dev:all_containers`
(Windows: `run.bat --test-map dev:all_containers`).
